# FamilyMesh

Private, decentralized, end-to-end encrypted family messaging for Android.

## Project status

The project is being built from the ground up. Milestone 0 establishes the Android application foundation.

## Platform

- Minimum Android version: Android 12 (API 31)
- Language: Kotlin
- UI: Jetpack Compose
- Architecture: modular, layered Android application

See `docs/architecture/overview.md` for the initial architecture and `docs/roadmap.md` for milestones.
